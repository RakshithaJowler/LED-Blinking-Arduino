# LED-Blinking-Arduino
Basic LED Blinking project using  Arduino

## Components

- Arduino Uno
- LED
- 220Ω resistor
- Jumper wires

## Working

The Arduino controls the LED connected to digital pin 13. The LED turns ON for 1 second and OFF for 1 second continuously.
